1 · Konsep Koordinat

Robot harus bergerak dari A → B → C → D mengikuti koordinat berikut:

A = (0,0)B = (5,0)C = (5,5)D = (10,5)
Catatan penting: koordinat geografis GPS berbeda dengan estimasi posisi robot di lingkungan indoor. Sistem navigasi AMR sering menggabungkan beberapa sensor sekaligus (misalnya encoder + IMU untuk odometri, dibantu LiDAR untuk koreksi posisi).

2 · Rancang Alur Sistem Sensor
